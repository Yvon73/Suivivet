**📜 Organismes Officiels pour les Animaux Domestiques en France
🐕 1. Organismes pour les CHIENS
🔹 LOF (Livre des Origines Français)
Description :
Le LOF (Livre des Origines Français) est le registre officiel des chiens de race en France, géré par la Société Centrale Canine (SCC).
Il atteste de la pureté de la race et permet de participer à des expositions, concours, et élevages.

Rôle :
Enregistrement des chiens de race (avec pédigrée).
Contrôle des lignées (éviter les croisements non conformes).
Organisation d’expositions canines.
Attribution des titres de champion.

Avantages :
Preuve de la race pure (important pour la valeur du chien).
Accès aux compétitions (expositions, agility, etc.).
Suivi généalogique (éviter les maladies héréditaires).

Site officiel : https://www.centrale-canine.fr/

Coût :
Inscription d’un chiot : ~20-50 € (selon la race).
Transfert de propriété : ~25 €.

Races concernées : Toutes les races reconnues par la FCI (Fédération Cynologique Internationale).

🔹 SCC (Société Centrale Canine)
Description :
La SCC est l’organisme officiel qui gère le LOF et représente la France auprès de la FCI.
Elle supervise aussi les clubs de race et les épreuves canines.

Rôle :
Gestion du LOF.
Reconnaissance des clubs canins.
Organisation des expositions et compétitions.
Formation des juges et éleveurs.

Site officiel : https://www.centrale-canine.fr/

🔹 FCI (Fédération Cynologique Internationale)
Description :
La FCI est l’organisme mondial qui définit les standards des races canines et organise les compétitions internationales.

Rôle :
Reconnaissance des races (360+ races classées en 10 groupes).
Harmonisation des standards (ex: taille, poids, couleur).
Organisation des championnats du monde.

Site officiel : https://www.fci.be/

🐍 5. Organismes pour les REPTILES et AMPHIBIENS
🔹 AFA (Association Française des Amateurs de Reptiles et Amphibiens)
Description :
L’AFA est une association dédiée aux reptiles et amphibiens, qui promeut leur détention responsable.

Rôle :
Conseils aux propriétaires.
Lutte contre les espèces invasives.
Organisation de salons.

Site officiel : https://www.afa-reptiles.com/

🔹 UICN (Union Internationale pour la Conservation de la Nature)
Description :
L’UICN est une organisation mondiale qui travaille sur la protection des espèces menacées, y compris les reptiles et amphibiens.

Rôle :
Liste rouge des espèces menacées.
Recommandations pour la détention.
Lutte contre le trafic illégal.

Site officiel : https://www.uicn.fr/

🔹 CITES (Convention sur le commerce international des espèces de faune et de flore sauvages menacées d'extinction)
Description :
La CITES est un accord international qui régule le commerce des espèces protégées, y compris certains reptiles et amphibiens.

Rôle :
Liste des espèces protégées (Annexes I, II, III).
Contrôle des importations/exportations.
Lutte contre le trafic illégal.

Site officiel : https://cites.org/fr

Espèces concernées en France :
Serpents : Python, Boa, Anaconda (déclaration obligatoire).
Lézards : Iguane, Caméléon (déclaration obligatoire).
Tortues : Tortue d’Hermann, Tortue sulcata (déclaration obligatoire).

from django.db import models

class Organisme(models.Model):
    nom = models.CharField(max_length=100, unique=True, verbose_name="Nom de l'organisme")
    description = models.TextField(blank=True, verbose_name="Description")
    site_web = models.URLField(blank=True, verbose_name="Site web")
    espece = models.CharField(
        max_length=50,
        choices=[
            ('CHIEN', 'Chien'),
            ('CHAT', 'Chat'),
            ('RONGEUR', 'Rongeur'),
            ('OISEAU', 'Oiseau'),
            ('REPTILE', 'Reptile/Amphibien'),
            ('POISSON', 'Poisson'),
        ],
        verbose_name="Espèce concernée"
    )
    logo = models.ImageField(upload_to='organismes/', blank=True, null=True, verbose_name="Logo")

    def __str__(self):
        return self.nom

    class Meta:
        verbose_name = "Organisme"
        verbose_name_plural = "Organismes"
        ordering = ['nom']

class Animal(models.Model):
    # ... (autres champs existants)
    organisme = models.ForeignKey(
        Organisme,
        on_delete=models.SET_NULL,
        null=True,
        blank=True,
        verbose_name="Organisme (LOF, LOOF, etc.)",
        help_text="Organisme officiel auquel l'animal est inscrit (ex: LOF pour les chiens, LOOF pour les chats)."
    )
    numero_identification = models.CharField(
        max_length=50,
        blank=True,
        null=True,
        verbose_name="Numéro d'identification",
        help_text="Numéro LOF, LOOF, ou autre identifiant officiel."
    )

    def __str__(self):
        return self.nom

from django import forms
from .models import Animal, Organisme

class AnimalForm(forms.ModelForm):
    class Meta:
        model = Animal
        fields = [
            'nom', 'race', 'espece', 'identification', 'organisme',
            'numero_identification', 'date_naissance', 'date_deces',
            'lof', 'robe', 'propriétaire'
        ]
        widgets = {
            'date_naissance': forms.DateInput(attrs={'type': 'date'}),
            'date_deces': forms.DateInput(attrs={'type': 'date'}),
            'organisme': forms.Select(attrs={'class': 'form-select'}),
        }

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        # Filtrer les organismes par espèce sélectionnée
        if 'espece' in self.data:
            espece = self.data['espece']
            self.fields['organisme'].queryset = Organisme.objects.filter(espece=espece)
        elif self.instance and self.instance.espece:
            self.fields['organisme'].queryset = Organisme.objects.filter(espece=self.instance.espece)

class AnimalDetailView(LoginRequiredMixin, DetailView):
    model = Animal
    template_name = 'animaux/detail.html'
    context_object_name = 'animal'

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        animal = self.get_object()
        context['age'] = animal.age()
        context['poids_list'] = animal.poids.all().order_by('date')

        # Ajouter les informations sur l'organisme
        if animal.organisme:
            context['organisme'] = animal.organisme

        return context

💡 Conseils pour les Propriétaires
Pour les chiens et chats de race :
Inscrire son animal au LOF ou LOOF pour obtenir un pédigrée officiel.
Vérifier les éleveurs : Un éleveur sérieux fournit toujours un certificat LOF/LOOF pour les portées.
Participer aux expositions pour valoriser son animal.

Pour les reptiles et amphibiens :
Vérifier la législation : Certaines espèces (Python, Iguane, etc.) nécessitent une déclaration obligatoire (CITES).
Éviter les espèces sauvages : Privilégier les animaux nés en captivité avec un certificat CITES.

Pour les oiseaux :
Vérifier les standards : Certaines races (perroquets, etc.) nécessitent un certificat d’origine.
Éviter les espèces protégées : Certaines espèces (ex: perroquets exotiques) sont interdites à la détention sans autorisation.

from django.db import models

class Organisme(models.Model):
    nom = models.CharField(max_length=100, unique=True, verbose_name="Nom")
    nom_court = models.CharField(max_length=10, blank=True, verbose_name="Sigle")
    description = models.TextField(blank=True, verbose_name="Description")
    site_web = models.URLField(blank=True, verbose_name="Site web")
    espece = models.CharField(
        max_length=20,
        choices=[
            ('CHIEN', 'Chien'),
            ('CHAT', 'Chat'),
            ('CHEVAL', 'Cheval'),
            ('RONGEUR', 'Rongeur'),
            ('OISEAU', 'Oiseau'),
            ('REPTILE', 'Reptile/Amphibien'),
            ('POISSON', 'Poisson'),
            ('ABEILLE', 'Abeille'),
            ('PIGEON', 'Pigeon'),
            ('AUTRE', 'Autre'),
        ],
        verbose_name="Espèce concernée"
    )
    pays = models.CharField(max_length=50, default="France", verbose_name="Pays")
    logo = models.ImageField(upload_to='organismes/', blank=True, null=True, verbose_name="Logo")
    est_officiel = models.BooleanField(default=True, verbose_name="Organisme officiel")
    date_creation = models.DateField(blank=True, null=True, verbose_name="Date de création")

    def __str__(self):
        return f"{self.nom} ({self.nom_court})"

    class Meta:
        verbose_name = "Organisme"
        verbose_name_plural = "Organismes"
        ordering = ['nom']

class Animal(models.Model):
    # ... (autres champs existants)
    organismes = models.ManyToManyField(
        Organisme,
        blank=True,
        verbose_name="Organismes",
        help_text="Organismes auxquels l'animal est inscrit (ex: LOF, LOOF, CITES)."
    )
    numero_identification = models.CharField(
        max_length=50,
        blank=True,
        null=True,
        verbose_name="Numéro d'identification",
        help_text="Numéro LOF, LOOF, SIRE, CITES, etc."
    )

    def get_organismes_list(self):
        """Retourne une liste des noms des organismes de l'animal."""
        return [org.nom for org in self.organismes.all()]

    def __str__(self):
        return self.nom
